# 💰 Personal Finance Tracker (Expense Manager)

A robust, user-friendly desktop application designed to track personal income and expenses. Built with Python and PyQt6, this tool provides a seamless interface for financial management, complete with dynamic filtering and local database storage.

## ✨ Features
* **Intuitive User Interface:** Clean and modern UI built with Qt Designer.
* **Income & Expense Tracking:** Easily log financial transactions with specific categories (Salary, Groceries, Rent, Bills, etc.).
* **Dynamic Filtering & Search:**  Filter records by 'All', 'Income', or 'Expense'.
* **Local Database:** All data is securely stored locally using SQLite, ensuring complete privacy.
* **Factory Reset:** A one-click database wipe feature for a fresh start.

## 🛠️ Technologies Used
* **Language:** Python 3.x
* **GUI Framework:** PyQt6
* **Database:** SQLite3
* **Design Tool:** Qt Designer

## 🚀 How to Run (Local Environment)
1. Clone this repository to your local machine:
   `git clone https://github.com/serkan-bes/Expense-Manager.git`
2. Ensure you have the required libraries installed:
   `pip install PyQt6`
3. Run the application:
   `python main.py`
